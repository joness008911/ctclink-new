# CleanTraffic PHP Protection Package
# Installation Guide for Universal Web Hosting

## QUICK START GUIDE

### Step 1: Upload Files
1. Download the CleanTraffic PHP Protection package
2. Extract all files to your desired location:
   - Root domain: public_html/
   - Subfolder: public_html/protection/
   - Custom folder: public_html/cleantraffic/

### Step 2: Set File Permissions
Set these file permissions via File Manager or FTP:
- All .php files: 644
- All .html files: 644
- All .txt files: 600 (secure)
- .htaccess file: 644

### Step 3: Access Admin Panel
1. Go to: http://yourdomain.com/[folder]/index.html
2. Login with default password: admin123
3. IMPORTANT: Change password immediately!

### Step 4: Configure System
1. Enter your CleanTraffic API key
2. Set Human Visitor redirect URL (your website)
3. Set Bot redirect URL (competitor/decoy site)
4. Test API connection
5. Copy your generated redirect link

### Step 5: Use Your Protection
Share the redirect link: http://yourdomain.com/[folder]/redirect.php
- Human visitors → Your website
- Bots → Decoy website
- Real-time analytics in admin panel

## HOSTING COMPATIBILITY

### cPanel Hosting
- Upload via File Manager or FTP

- No special configuration needed

### aaPanel / CyberPanel
- Upload to web directory
- Ensure PHP 7.0+ enabled
- Set proper file permissions

### VPS / Dedicated Server
- Upload to document root or subdirectory
- Ensure Apache/Nginx + PHP configured
- Verify .htaccess support enabled

### Shared Hosting
- Works on 99% of shared hosting
- Requires PHP 7.0+ with cURL extension
- No database required

## TROUBLESHOOTING

### Common Issues

1. "API key not working"
   - Verify API key is correct
   - Check CleanTraffic account status
   - Test API connection in admin panel

2. "Permission denied errors"
   - Set file permissions to 644 for .php/.html
   - Set 600 for .txt files
   - Ensure web server can write to directory

3. "Redirects not working"
   - Check redirect URLs are valid
   - Verify .htaccess is supported
   - Test with different browsers

4. "Admin panel won't load"
   - Check index.html file permissions
   - Verify PHP is working
   - Clear browser cache
